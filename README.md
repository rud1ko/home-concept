# LINEA 9×12 — как посмотреть альбом

Современный двухэтажный дом **9 × 12 м** на участке **17 × 35 м**.  
Клонировать репозиторий и ставить Python **не нужно**.

## Самый простой способ

1. На GitHub нажмите зелёную кнопку **Code → Download ZIP**.
2. Распакуйте архив.
3. Откройте файл:

```
house-9x12/index.html
```

Двойной щелчок — альбом откроется в браузере (Chrome, Safari, Firefox).  
Нужны картинки и чертежи рядом с этим файлом, ничего не переименовывайте и не вытаскивайте `index.html` из папки.

## Если репозиторий уже скачан

Откройте в браузере тот же файл:

```
house-9x12/index.html
```

Из терминала на macOS:

```bash
open house-9x12/index.html
```

## Что внутри

| Файл / папка | Содержание |
|---|---|
| `index.html` | Альбом: генплан, планы этажей, фасады, разрез, визуализации |
| `images/` | Картинки дома и интерьеров |
| `drawings/` | Чертежи А-01…А-06 (SVG) |
| `generate_album.py` | Скрипт пересборки чертежей, для просмотра не нужен |

Это концептуальный проект, не рабочая документация для строительства.
